# 数据可视化分析仪表盘

一个纯前端的数据可视化动态仪表盘，基于 ECharts 5，内置模拟数据源，开箱即用。

## 功能特性

- **多图表联动**：折线图（访问趋势）、环形图（流量来源）、横向条形图（品类排行）、仪表盘（目标完成率）、漏斗图（转化漏斗）
- **KPI 指标卡**：数字滚动动画 + 环比涨跌标识
- **时间范围切换**：实时 / 今日 / 本周 / 本月，一键重新生成数据
- **实时刷新**：实时模式下每 5 秒自动刷新，支持手动刷新
- **响应式布局**：自适应桌面与移动端
- 深色科技风 UI

## 使用方法

直接用浏览器打开 `index.html` 即可（图表库通过 CDN 加载，需联网）。

## 接入真实数据

所有数据由 `dashboard.js` 中的模拟数据函数生成（`genKpi` / `genSeries` / `genSources` 等），
将这些函数替换为真实 API 请求即可接入生产数据。
